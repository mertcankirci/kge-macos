# kge-macos

## Description
KGE is designed to be your future personal assistant for daily and work-related tasks. In its initial phase, our primary focus is on creating a **laser-focused environment** tailored to users' specific needs.

## Golden Rule 
First thing's first: the goal of this project is for every contributor to truly master iOS and macOS development. To maintain this learning integrity, we have one non-negotiable rule:
* **NO AI USAGE IS ALLOWED.**
* If you need information to move forward with a specific feature, please consult the **Apple Documentation** or **Stack Overflow** — just like in the good old days. :)
